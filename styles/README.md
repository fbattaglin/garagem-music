# Styles

One file per style: what kind of song, said once (ADR-030).

A style is described by what the band does, never by a song. `reference` names the bands a
person would think of; `direction` is what the songwriter is told, in the notation's own terms;
`feels`, `scales` and `bpm` are the palette a new song in the style starts from.

Today only the songwriter and the studio read a style. The players do not: they play every
style with the same hands, so a style changes what is written and not yet how it sounds.

To add one, copy a file, rename it and rewrite its direction. `garagem studio` lists them
under `styles`.
